# Contributing

Thank you for your interest in contributing to
ai-plugins.

## How to Contribute

1. Fork this repository and create a feature branch.
2. Make your changes following the conventions
   described in `CLAUDE.md`.
3. Open a pull request against `main`.

## Guidelines

- Keep pull requests focused on a single topic.
- Follow the markdown conventions defined in
  this repository (see `CLAUDE.md`).
- Provide clear context in your PR description
  explaining **why** the change is needed.

## Review Process

All contributions require at least one review
before merging. Reviewers will check for
consistency with existing conventions and
clarity of the proposed guidelines.
