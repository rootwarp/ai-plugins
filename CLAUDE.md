# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

`ai-plugins` is a Claude Code plugin marketplace (Go, Rust, Python, and dev-team plugins) maintained by
rootwarp. Plugins live under `plugins/`; the marketplace manifest is `.claude-plugin/marketplace.json`.

## Markdown Conventions

- Use `#` for the document title (one per file), `##` for sections, `###` for subsections
- Leave a blank line before and after headings, code blocks, and lists
- Use `-` for unordered lists, `1.` for ordered lists
- Indent nested lists with 2 spaces
- Use fenced code blocks (```) with a language identifier for syntax highlighting
- Use single backticks for inline code references
- Limit lines to 100 characters where practical
- End files with a single newline
- Use reference-style links `[text][id]` when the same URL is used multiple times
