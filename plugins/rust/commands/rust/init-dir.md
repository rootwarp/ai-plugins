# /rust:init-dir

Initialize a standard Rust project with Cargo configuration and common setup.

## Instructions

### Step 1: Gather Information

Ask the user:
1. **Project type:**
   - Binary (recommended) - executable application
   - Library - reusable library crate
   - Workspace - multi-crate project

2. **Project name** (used for package name and directory)

3. **Additional features:**
   - Async runtime (tokio/async-std/none)
   - Serialization (serde)
   - CLI parsing (clap)
   - Error handling (thiserror/anyhow)

### Step 2: Initialize with Cargo

**Binary Project:**
```bash
cargo init <project-name>
cd <project-name>
```

**Library Project:**
```bash
cargo init --lib <project-name>
cd <project-name>
```

**Workspace Project:**
```bash
mkdir <project-name>
cd <project-name>
mkdir crates
```

### Step 3: Create Directory Structure

**Binary / Library Project:** `cargo init` already created `src/`. Add `tests/`, `examples/`,
and `benches/` when their first file exists — not preemptively (see `rust-project-layout`).

**Workspace Project:**
```bash
cargo init --lib crates/core
cargo init crates/cli
```

### Step 4: Configure Cargo.toml

For single crate project:

```toml
[package]
name = "<project-name>"
version = "0.1.0"
edition = "2024"
rust-version = "1.85"
description = "A brief description"
license = "MIT OR Apache-2.0"
repository = "https://github.com/username/<project-name>"

[dependencies]

[dev-dependencies]

[profile.release]
lto = true
strip = true
```

For workspace project, create root `Cargo.toml`:

```toml
[workspace]
resolver = "3"
members = ["crates/*"]

[workspace.package]
version = "0.1.0"
edition = "2024"
rust-version = "1.85"
license = "MIT OR Apache-2.0"
repository = "https://github.com/username/<project-name>"

[workspace.dependencies]
# Shared dependencies go here
```

### Step 5: Add Selected Dependencies

Based on user choices, add to `Cargo.toml`:

**Async (tokio):**
```toml
tokio = { version = "1", features = ["full"] }
```

**Serialization:**
```toml
serde = { version = "1", features = ["derive"] }
serde_json = "1"
```

**CLI:**
```toml
clap = { version = "4", features = ["derive"] }
```

**Error handling:**
```toml
thiserror = "2"
anyhow = "1"
```

### Step 6: Create Source Files

**Binary (`src/main.rs`):**
```rust
fn main() {
    println!("Hello, world!");
}
```

**Library (`src/lib.rs`):**
```rust
//! # <project-name>
//!
//! A brief description of the library.

pub fn add(left: u64, right: u64) -> u64 {
    left + right
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn it_works() {
        let result = add(2, 2);
        assert_eq!(result, 4);
    }
}
```

### Step 7: Write .gitignore

Create `.gitignore`:

```gitignore
# Generated by Cargo
/target/

# IDE
.idea/
.vscode/
*.swp
*.swo
*~

# OS files
.DS_Store
Thumbs.db

# Environment files
.env
.env.local
*.env

# Build artifacts
*.so
*.dylib
*.dll

# Coverage
*.profraw
*.profdata
coverage/
tarpaulin-report.html
```

Note: Commit `Cargo.lock` (current Cargo guidance for both binaries and libraries). Add it to
`.gitignore` only if a library explicitly prefers not to track it.

### Step 8: Write rustfmt.toml

Create `rustfmt.toml`:

```toml
edition = "2024"
max_width = 100
use_small_heuristics = "Default"
```

### Step 9: Write clippy.toml (optional)

Create `clippy.toml` for custom lint configuration:

```toml
too-many-arguments-threshold = 7
```

### Step 10: Write rust-toolchain.toml (optional)

Create `rust-toolchain.toml` for consistent toolchain:

```toml
[toolchain]
channel = "stable"
components = ["rustfmt", "clippy"]
```

### Step 11: Write deny.toml (optional)

Create `deny.toml` for `cargo deny check` (see the `rust-security` skill for the v2 format):

```toml
[advisories]
yanked = "warn"

[licenses]
allow = ["MIT", "Apache-2.0", "BSD-3-Clause", "Unicode-3.0"]

[bans]
multiple-versions = "warn"
```

### Step 12: Create Makefile (optional)

Create `Makefile` for common tasks:

```makefile
.PHONY: all build build-release run test test-verbose lint fmt fmt-check audit clean doc help

all: build

build: ## Build the project
	cargo build

build-release: ## Build release version
	cargo build --release

run: ## Run the application
	cargo run

test: ## Run tests
	cargo test --all-features

test-verbose: ## Run tests with output
	cargo test -- --nocapture

lint: ## Run clippy
	cargo clippy --all-targets --all-features -- -D warnings

fmt: ## Format code
	cargo fmt --all

fmt-check: ## Check formatting
	cargo fmt --all --check

audit: ## Check advisories, licenses, bans, and sources
	cargo deny check

clean: ## Clean build artifacts
	cargo clean

doc: ## Generate documentation
	cargo doc --open

help: ## Show this help
	@grep -E '^[a-zA-Z_-]+:.*?## .*$$' $(MAKEFILE_LIST) | sort | awk 'BEGIN {FS = ":.*?## "}; {printf "\033[36m%-15s\033[0m %s\n", $$1, $$2}'
```

### Step 13: Display Result

Show the created structure using `tree` or `ls -la` and confirm completion.

Run the quality gate from the `rust-code-style` skill:
```bash
cargo fmt --all
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
```

## Rules

- Use `cargo init` as the starting point
- Follow standard Cargo project layout
- Commit `Cargo.lock` (binaries and libraries alike, per current Cargo guidance)
- Use edition 2024
- Add `rust-version` to specify MSRV
